# 店主向け：MEO Harness の始め方

現在は一般公開前です。ローカルの架空データで確認する自己登録機能で、本番の受付は既定で停止しています。公開前チェックを通過した運営者のサービス URL から始めてください。

1. `/start` の説明・利用枠・データの取り扱いを確認し、「Googleで接続」を選びます。
2. ご本人がGoogleの画面でログインし、権限を確認します。お店を管理できるアカウントを使ってください。パスワードをMEO HarnessやAIに渡す必要はありません。
3. 表示された店舗名を確認して「この店舗を使う」を選びます。1店舗だけでも確認が必要です。
4. LINEの友だち追加リンクまたはQRを開き、画面の登録コードをボットへ送ります。コードの有効期限は15分です。違うLINEで送った場合はコードを再発行してください。
5. 元のブラウザで「確認番号をLINEに送る」を選び、LINEに届いた6桁を入力します。番号は5分間、照合は5回まで。送信は1分1回・1日3回までです。画面を別のブラウザに変えた場合は登録コードからやり直します。
6. 利用条件・上限を確認し「利用を開始する」を選びます。初回は直近60日の未返信から5件まで下書きし、残りは後続処理に残します。通知は原則JST9時以降に1日1回です。
7. LINEに届いた返信案を読み、口コミごとに承認した後だけGoogleへ投稿します。長い口コミは自分のアカウントで全文を確認できます。

## 続きから・うまくいかないとき

`/account` で続きに戻れます。ログインは24時間で期限切れになるため、Googleで再ログインしてください。店舗0件とAPIエラーは別表示です。店舗0件ならGoogleアカウント、接続切れなら再接続、利用枠不足なら次の枠まで待機します。自動課金や追加購入はしません。

接続確認、LINEへのAPI受付、実際の到達、Googleへの投稿確認は別の状態です。口コミが0件でも接続はできます。架空の口コミをGoogleへ投稿することはありません。

### よくある質問・問題の報告

サービス内の `/self/help/faq` に、Google接続・LINE通知・投稿結果・停止などのFAQがあります。ログインできない途中でも読めます。

解決しない場合は `/self/help/report` で相談内容を整理してください。確認後にメールアプリを開くか、本文をコピーして、MEO専用の窓口 `meo.harness@gmail.com` へ自分で送信します。画面で入力・確認しただけでは送信も受付も完了しません。返信は送信元のメールアドレスへ行う運用です。LINEは一般的な質問に回答するサポートチャットではありません。

パスワード・認証コード・確認番号・APIキー・お客様の個人情報・Google認証画面のURLは送らないでください。画像は必要な場合だけ、個人情報を隠してメール側で添付します。フォームの内容はサービスへ自動送信・保存しません。即時返信や一定時間内の解決は保証しません。公開前に運営者が窓口の受信・返信と公開内容を最終確認します。

## 停止・切断

「利用を停止」は新たな取得・下書き・通知・投稿を停止します。すでにGoogleが受理した返信を取り消すことはできません。「接続を切断」は確認後にローカルの資格情報・口コミ本文・返信案を削除します。公開済み返信は削除しません。Googleアカウントの接続済みアプリ管理からアクセス権限を取り消すこともできます。

## 保存と上限

認証情報は暗号化し、未完了の接続情報は最終操作から24時間、口コミ・返信本文は7日、操作記録は30日を削除基準とします。定期処理で順次削除するため遅れが生じる場合があります。稼働中は重複防止のため最小限の口コミ識別子・処理結果を保持し、切断で削除します。月別利用記録は対象月末と作成からともに90日以上経過後に順次削除します。FreeプランのD1復元用履歴は7日分が残ります。登録画面の「プライバシー」と「利用条件」から、保存先・外部サービス・問い合わせ先も確認できます（現在のHTMLはローカル案で未公開）。

LINEを無条件に無料とは案内しません。共有チャネルの残量が不足・不明なときは処理を保留します。停止後の古い承認ボタンは使えません。再開後に届く新しい通知を確認してください。

## 承認した後の結果

LINEの操作への返信と、`/account`の「最近の返信結果」で、投稿確認・スキップ・競合・期限切れを区別します。LINEへの結果返信が届かない場合もアカウント画面で確認できます。送信結果が不明な場合は自動再投稿しません。「未投稿を確認。LINEで再承認してください」と出たときだけ、同じ本文を確認してLINEの承認をもう一度押してください。

送信枠待ちの未生成口コミは本文保持期限後も未処理の記録を残し、Googleから再取得して処理します。承認待ちの本文は7日で失効します。下書き保存の障害が続く場合は自動再生成を止めます。再生成を希望して停止→再開する場合、下書き利用枠を再び消費する点を確認してください。
