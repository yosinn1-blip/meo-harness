## 実装

- 明確な ja/en/ko には返信言語を指定。入力は言語中立な JSON とし、レビュー内の命令を指示扱いしない。
- 提供済み固有名詞を除外して言語推定。漢字のみ・空・絵文字など低確信の入力は `auto` とし、無理に英語固定・拒否しない。従来の公開 `detectLang` の既定値は互換維持。
- 既知の `顶戴`、意図しない Hangul、明白な ja/en/ko の言語違い、和英の名前プレースホルダー、空・短すぎる返答を検査。一般的な漢字を外国語扱いしない。
- 品質警告時のみ既存 `maxRetries` 内で再生成し、残存時は `text: ""` と警告を返す。HTTP 429 等は品質ループで再試行しない。使用 token 数は失敗案も合計。
- 旧通知経路では空の案を null に変換し、承認 ID を通知に引き継がない。Flex も空本文に承認ボタンを出さない。
- 日次の再生成が成功したら新 ID にその本文を保存し、同じ ID/本文を通知する。拒否後の回復でも承認可能。旧 ID の KV レコード自体は削除せず既存 TTL に任せる。
- self-service は既存 `maxRetries: 0` を維持。無効案を replies に保存せず、使用枠は消費し、既存のジョブ上限・バックオフで処理待ちにする。新しい再試行系統は追加していない。

## 保証しないこと

- これは一般的な事実確認器ではない。未確認の返金・折り返し連絡・キャンペーン・来店歴等を禁止するプロンプトでも、意味的な補完は残り得る。
- `auto` の言語、英語と他のラテン文字言語の区別、全ての文字混入を自動判定できるわけではない。
